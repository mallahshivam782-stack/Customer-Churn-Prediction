Customer Churn Prediction

**1. Project Overview**
Customer Churn Prediction is a Data Science and Machine Learning project that predicts whether a customer is likely to leave a company.

This project uses customer information from the IBM Telco Customer Churn dataset to analyse customer behaviour and build prediction models.

**2. Objectives**
- Analyse customer data.
- Understand customer churn patterns.
- Clean and preprocess the dataset.
- Train machine learning models.
- Compare model performance.

**3. Technologies Used**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

**4. Dataset**
**Dataset:** IBM Telco Customer Churn

The dataset contains customer details, services, contract information, monthly charges and churn status.

**5. Machine Learning Algorithms**
1. Logistic Regression
2. Random Forest Classifier

**7. Results**
Two machine learning models were trained and evaluated:
- Logistic Regression
- Random Forest

Their accuracy and evaluation reports were compared to understand their performance.

**8. Conclusion**
This project demonstrates how machine learning can be used to predict customer churn. It also helps identify customer behaviour patterns that can support businesses in improving customer retention.
